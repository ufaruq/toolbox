# Toolbox design artifacts

For implemented behavior and remaining work, see the [current roadmap](../ROADMAP.md) and [application verification](../implementation-status.md). This directory records the architecture and design artifacts merged in PR #1; its design checks are separate from application test results.

Read [the design](user-delegated-connections.md) or [the PDF](user-delegated-connections.pdf). The canonical editable source is [source/build_design.py](source/build_design.py): it contains the prose, tables, document formatting and all five diagram definitions. The Markdown, SVGs and PDF are generated outputs, not independent hand-edited sources.

## Rebuild

Prerequisites: Python 3.12, LibreOffice (`soffice` on PATH), Poppler (`pdftoppm` for page images), and the Liberation Sans, DejaVu Sans and DejaVu Sans Mono fonts. Install packages using your platform's normal package manager. The document explicitly uses these freely available font families rather than relying on a proprietary font fallback.

From the repository root:

```sh
python3 -m venv docs/design/.venv
docs/design/.venv/bin/python -m pip install -r docs/design/source/requirements.txt
docs/design/.venv/bin/python docs/design/source/render.py --pages
```

This builds:

- `.build/Toolbox_User_Delegated_Connections_Design.docx`: editable Word document
- `.build/pages/page-*.png`: every PDF page for visual review
- `user-delegated-connections.md`: review text exported from the same DOCX
- `user-delegated-connections.pdf`: LibreOffice rendition of that DOCX
- `diagrams/*.svg`: diagrams generated by the same source

The renderer creates an isolated temporary LibreOffice profile. It needs no proprietary template, account, network service or absolute path from the original authoring machine. `--output-dir` and `--dest` support clean out-of-tree builds.

## Check reproducibility and layout

```sh
docs/design/.venv/bin/python docs/design/source/render.py \
  --output-dir /tmp/toolbox-design-build --dest /tmp/toolbox-design-review --pages
diff docs/design/user-delegated-connections.md /tmp/toolbox-design-review/user-delegated-connections.md
diff -r docs/design/diagrams /tmp/toolbox-design-review/diagrams
```

The SVG generator uses a fixed hash salt and omits its timestamp, so identical inputs and dependency versions produce identical SVGs. PDF/DOCX metadata can differ between runs, and LibreOffice/font versions can affect pagination; byte-for-byte PDF equivalence across operating systems is not promised. Review all generated page images after changes, especially table boundaries, diagram labels, page numbers and any page-count change. Do not edit only an SVG XML comment: labels must change in the generator and be rendered again.

The reviewed v0.2 build used Python 3.12.14, python-docx 1.2.0, Matplotlib 3.10.8, LibreOfficeDev 26.8.0.0.alpha0 (commit 2c87e51eeaa2b413ff4ae097b2705eea1995d8e5), and Poppler 26.05.0 on Linux. The LibreOffice version is a record of the rendering environment, not a production deployment recommendation. Use a supported LibreOffice release for your workstation and inspect any layout differences.

## Review workflow

Edit `source/build_design.py`, regenerate, inspect every page, and commit the source and generated Markdown/PDF/SVG changes together. Update [review-checks.md](review-checks.md) with actual checks. Keep later corrections as separate commits; do not squash or force-rewrite review history. Application/provider tests described in the document remain implementation requirements until run and reported separately.
