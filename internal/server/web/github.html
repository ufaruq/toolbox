01 / CONNECT

Your GitHub repositories

These repositories are available to your installed GitHub App. Connecting one does not grant an agent access.

02 / REVIEW

Requests for access

An agent requests actions, branches, paths and an expiry through MCP. Review the full scope before approving.

Multi-file writes can overwrite concurrent changes and replace directories within the approved scope. Approve this only when the agent should control that scope.

PR operations can affect the whole pull request, including files outside file-operation paths. Branch restrictions are checked before dispatch; concurrent external retargeting cannot be locked by Toolbox.

03 / MANAGE

Active and past grants

Revocation blocks further operations. It cannot undo changes already made on GitHub.

Enable GitHub for your MCP caller in Workspace → Agent clients. The caller still needs a repository grant for every operation.
